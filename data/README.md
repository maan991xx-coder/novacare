# بيانات ناسا الحقيقية → محرك VITALX

المصدر المُتحقق منه: **NASA OSDR Environmental Data App (EDA)**
https://visualization.osdr.nasa.gov/eda/ — قياسات مقصورة محطة الفضاء الدولية (CO2، الحرارة، الرطوبة) وجرعة الإشعاع اليومية (GCR، SAA، Total، Accumulated) لكل مهمة (RR-1 … RR-28، APEX، VEG-01C). التنزيل من جدول Data Tables بصيغة CSV أو Excel.

## الخطوات
1. افتح EDA ← Data Tables ← اختر مهمة (مثلا RR-12) ← جدول Telemetry ← CSV.
2. احفظ الملف في `data/` ثم شغّل:
   ```
   node data/nasa-eda-adapter.js data/<file>.csv
   ```
3. المخرجات: خط الأساس الشخصي من أول 14 يوما، أيام إنذار CUSUM، ومقارنة بحد ناسا الثابت 3 mmHg (NASA-STD-3001 V2 6004).

المحرك نفسه (`engine.js`) لا يتغير. إذا اختلفت أسماء الأعمدة استخدم `--column CO2`.

## نتيجة أول تشغيل على بيانات حقيقية: RR-12 (2019-04-17 → 2019-05-28)
ملفات `data/nasa/` منزّلة من EDA API (`/eda/api/missions/RR-12/telemetry_data/` و `radiation_data/`).

- أول 5 أيام قيمة CO2 ثابتة 3000 ppm (قيمة تعبئة) فاستُبعدت تلقائيًا.
- CO2 الحقيقي: وسيط يومي 2.02 mmHg، أعلى وسيط يومي 2.37 mmHg، أعلى متوسط ساعة 2.77 mmHg. لا إنذار من VITALX ولا تجاوز لحد 3 mmHg ⇒ **لا إنذارات كاذبة على مهمة مستقرة**.
- الحرارة والرطوبة وجرعة الإشعاع (GCR و Total): لا إنذارات.
- اختبار حساسية (انجراف مصطنع فوق البيانات الحقيقية، `--inject-drift 0.05 --from-day 16`): VITALX نبّه 2019-05-19، والحد الثابت 3 mmHg تجاوز أول مرة 2019-05-25 ⇒ **أبكر بـ 6 أيام**. مع 0.03/يوم: VITALX نبّه 05-20 والحد الثابت لم يُتجاوز أبدًا.
