# VITALX — فريق NovaCore · هاكاثون ناسا

نظام دعم قرار لطبيب الطاقم (وليس تشخيصاً). البيانات مولّدة، والسيناريوهات مبنية على مخاطر HRP.

## الموقع: 6 شاشات فقط (`index.html`)

| # | الشاشة | ماذا تعرض |
|---|---|---|
| 1 | الرئيسية | الرائد والقياسات الحية والطاقم |
| 2 | المشكلة | الانحراف البطيء يمر تحت الحد الثابت (رسم + 3 أرقام) |
| 3 | الحل | الساعة ولوحة طبيب الطاقم جنباً إلى جنب، تعرضان البيانات المحسوبة لحظياً |
| 4 | ما يميزنا | خط أساس لكل رائد، سبب كل تنبيه، إسقاط اتجاه 14 يوماً |
| 5 | العرض الحي | نظامنا مقابل الحد الثابت على الرائد نفسه، ونتائج 200 رائد محاكى |
| 6 | ناسا | ربط كل إشارة بمخاطر HRP، والإفصاح، وخانات الفريق والتحدي |

التنقل: السحب، أو الأسهم، أو أيقونات الشريط، أو الإمالة على الجوال. زر التشغيل يمرر أيام المهمة.

## التشغيل

افتح `index.html` في المتصفح. لا يحتاج تثبيتاً ولا خادماً. زر **English / العربية** يبدّل اللغة (أو `?lang=en`).

## الملفات

| الملف | ماذا فيه | هل تعدّله؟ |
|---|---|---|
| `content.js` | كل النصوص بالعربية والإنجليزية، والطاقم، وأرقام المحاكاة | **نعم، هنا فقط** |
| `engine.js` | robust_z و CUSUM ثنائي الاتجاه، ومولّد البيانات بمرحلة التكيف، والمقاييس، وإسقاط الاتجاه | نادراً |
| `site.js` | يرسم الشاشات الست من content.js و engine.js | لا |
| `styles.css` `appmode.css` `console.css` `six.css` `fonts.css` | التصميم (نسق لوحة المركبة) | للألوان فقط |
| `media/` | خلفية المركبة وصورة الرائد | — |
| `watch/` | نسخة الساعة (ملف HTML واحد) وتطبيق أندرويد للهواتف القديمة | — |

## خانات لم تُستكمل

أي نص بين `⟨ ⟩` يظهر بلون وردي متقطع. ابحثوا عن `⟨` في `content.js`: اسم التحدي، أسماء الأعضاء، اسم خطر HRP الخاص بـ CO2.
لا نذكر أي مجموعة بيانات من ناسا قبل التحقق منها.
