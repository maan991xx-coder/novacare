# VITALX — فريق NovaCore · هاكاثون ناسا

نظام دعم قرار لطبيب الطاقم (وليس تشخيصاً). البيانات مولّدة، والسيناريوهات مبنية على مخاطر HRP.

- `index.html`: **لوحة التحكم** (واجهة المركبة): الرئيسية، الطاقم، الرائد، الاتجاهات، التنبيهات، قرار الطبيب، المقصورة، العرض المرئي، الإعدادات. تعمل على الجوال أيضاً
- `details.html`: الصفحة التفصيلية (الشرح الكامل والمقارنة) بنفس النسق
- `devices.html`: الساعة والشريحة والنظام يعمل داخلهما
- `app.html`: تحويل تلقائي إلى `index.html` (للروابط القديمة)
- `watch/`: نسخة الساعة (ملف HTML واحد) وتطبيق أندرويد للهواتف القديمة

## التشغيل

افتح `index.html` مباشرة في المتصفح. لا يحتاج تثبيت أي شيء ولا خادم.
زر **English / العربية** في الأعلى يبدّل اللغة (أو أضف `?lang=en` للرابط).

## الملفات

| الملف | ماذا فيه | هل تعدّله؟ |
|---|---|---|
| `content.js` | كل النصوص بالعربية والإنجليزية، والحالات، والمراجع، وكل أرقام المحاكاة | **نعم، هنا فقط** |
| `engine.js` | robust_z و CUSUM ثنائي الاتجاه، ومولّد البيانات بمرحلة التكيف، والمقاييس، وإسقاط الاتجاه | نادراً |
| `app.js` | يرسم الصفحة والرسوم من content.js | لا |
| `styles.css` | الألوان والتصميم (المتغيرات في أول الملف) | للألوان فقط |
| `appmode.js` / `appmode.css` | وضع التطبيق. نصوصه والطاقم في `content.js` → `appMode` | لا |

## تعديلات شائعة في `content.js`

- **تغيير نص:** كل نص مكتوب هكذا `{ ar: "...", en: "..." }`. غيّر اللغتين معاً.
- **خانة لم تُستكمل:** أي نص بين `⟨ ⟩` يظهر بلون وردي متقطع حتى تستبدلوه. ابحثوا عن `⟨` لتجدوها كلها
  (اسم الفريق، اسم التحدي، مجموعة بيانات ناسا، اسم خطر HRP الخاص بـ CO2، أوراق NTRS، صياغة التنبيهات).
- **حالة عنصر:** غيّر `status` إلى `built` أو `designed` أو `future` أو `simulated` أو `pending`.
- **مجموعة بيانات ناسا بعد التحقق:** `data.nasaDataset` → ضعوا الاسم والرابط وغيّروا `status` إلى `built`.
- **قرارات الممرضين:**
  - الأوزان: `sim.channels.<id>.weight`
  - min_scale: `sim.channels.<id>.minScale` (`relative` نسبة من الوسيط، أو `absolute` بالوحدة نفسها مثل ساعات النوم)
  - العتبات الثابتة: `sim.fixed.thresholds`
  - رسائل التنبيه: `alerts`
- **k و h ونافذة الإسقاط:** `sim.personal.k`, `sim.personal.h`, `sim.projection.window`
  (ويمكن تجربتها حيّاً من لوحة التحكم في الموقع).
- **مرحلة التكيف:** `sim.adaptation.days` (أيام التجاهل) و `tau` (سرعة تلاشي أثر التكيف).

كل أرقام المحاكاة افتراضية للعرض، وليست قيماً سريرية.

## لوحة التحكم (`index.html`)

- التنقل بين الشاشات: اسحب بالماوس أو بالإصبع يميناً ويساراً، أو مرّر أفقياً على لوحة اللمس، أو الأسهم ← →، أو أسهم الحواف.
- على الجوال: زر **التنقل بالإمالة** ثم أمِل الجوال يميناً أو يساراً للانتقال للشاشة التالية أو السابقة.
- الأيام: PageUp / PageDown أو `[` `]`.

- الشاشات: الطاقم، الرائد (مقاييس دائرية وموجة قلب توضيحية ورسم الحساسات)، الاتجاهات، التنبيهات، قرار الطبيب، المقصورة، الإعدادات.
- التحكم: تشغيل/إيقاف، يوم واحد، السرعة، والسحب على خط الزمن. المسطرة (Space) تشغّل وتوقف.
- روابط مباشرة: `index.html?day=80#member/A` أو `#alerts` أو `#review`. و`?lang=en` للإنجليزية.
- التنبيه في يوم ما محسوب من بيانات ذلك اليوم وما قبله فقط، بالمحرك نفسه.
- الاقتراحات لا تُنفَّذ تلقائياً؛ الطبيب يعتمدها أو يرفضها مع سبب أو يحوّلها للأرض، وكل قرار يُحفظ في سجل (في المتصفح فقط).
- الطاقم في `content.js` → `appMode.crew`: رموز (أ، ب، ج، د) وليست أسماء أشخاص. `driftMult: 0` يعني رائداً مستقراً بلا انحراف.
